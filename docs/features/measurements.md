# Body Measurements

TailorMate lets you save detailed body measurements for each customer so you can reuse them for every new order — no need to measure again.

## Add Measurements for a Customer

1. Open the customer's profile from **Customers**.
2. Tap **Add Measurements**.
3. Enter the required measurements (chest, waist, hip, shoulder, sleeve length, etc.).
4. Tap **Save**.

## View Saved Measurements

1. Open the customer's profile.
2. Scroll to the **Measurements** section — all saved profiles are listed here.

## Use Measurements in an Order

When creating or editing an order:
1. Tap **Add Measurements**.
2. Select the customer's saved measurement profile.
3. The measurements are attached to that order automatically.

## Edit Measurements

1. Open the customer's profile.
2. Tap on the measurement profile you want to update.
3. Tap **Edit**, make your changes, and tap **Save**.

## Multiple Profiles

You can save more than one measurement profile per customer — useful if a customer has different measurements for different garment types (e.g., shirt vs. trousers).

---

:::tip
Always verify measurements with the customer before starting work on a new garment, even if you have a saved profile.
:::
