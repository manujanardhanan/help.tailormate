# Workers

The Workers section helps you manage your shop staff — tracking who does what, how much they're owed, and what you've paid them.

Go to **Workers** from the hamburger menu (☰).

## Worker List

The Worker List shows all staff members added to your shop.

### Add a Worker

1. Tap the **+** button.
2. Enter the worker's **name**, **phone number**, and **role**.
3. Tap **Save**.

Roles you can assign:
- Shop Manager
- Office Staff
- Worker
- Senior Staff
- Cutting Master
- Tailor
- Workshop Manager
- Delivery Boy

![Worker list](/img/screenshots/photo_58_2026-04-26_10-46-17.jpg)

## Roles & Permissions

Each role has a different level of access to the app. Assign the appropriate role to control what each worker can see and do.

To manage roles: go to **Workers** → **Roles & Permissions**.

![Roles and permissions](/img/screenshots/photo_60_2026-04-26_10-46-17.jpg)

## Dress Piece Rate

Set a **per-garment rate** for each worker. This defines how much a worker earns for completing each garment type.

1. Go to **Workers** → **Dress Piece Rate**.
2. Select a worker.
3. Set the rate for each garment type.

![Dress piece rate](/img/screenshots/photo_62_2026-04-26_10-46-17.jpg)

## Task Assignments

Assign specific production **tasks** (e.g., Cutting, Stitching) to workers for an order item.

1. Open an order and go to the **Tasks** section, or go to **Workers** → **Task Assignments**.
2. Select the order item.
3. Assign the task to the relevant worker.

## Dress Assignments

Assign complete garment jobs to workers.

1. Go to **Workers** → **Dress Assignments**.
2. Select the order item.
3. Assign it to a worker.

The worker will see their assigned work in their task view.

## Worker Dues

Track what you owe each worker based on completed work.

Go to **Workers** → **Worker Dues** to see:
- Garments completed by each worker
- Amount earned (based on piece rates)
- Amount already paid
- Outstanding balance

![Worker dues](/img/screenshots/photo_76_2026-04-26_10-46-17.jpg)

## Worker Payouts

Record payments made to workers.

1. Go to **Workers** → **Worker Payouts**.
2. Tap **Add Payout**.
3. Select the worker, enter the amount and date.
4. Tap **Save**.

The payout is deducted from the worker's outstanding dues.

![Worker payouts](/img/screenshots/photo_78_2026-04-26_10-46-17.jpg)

---

:::tip
Set up **Dress Piece Rates** for each worker so Worker Dues are calculated automatically as orders are completed.
:::
